# negative-keyword-builder

*Cluster: Keywords & Targeting . Part of the 35 Google Ads Skills set by Vicky Lalwani, Digital Marketing Director.*

## Purpose

Build the negative keyword lists that stop budget leaking on irrelevant, low-intent, or wrong-audience searches, applied at the right level with the right match types.

## When to use

- A new campaign needs pre-emptive negatives before launch
- Wasted spend is showing up in the search terms report
- Building a reusable account-level negative list
- Tightening a campaign attracting the wrong clicks

## Inputs required

- The product and who it's NOT for (required)
- Optional: the search terms report (to find real waste), the existing negative lists, the campaign structure

## Step-by-step instructions

1. Identify the obvious pre-launch negatives: 'free', 'cheap', 'jobs', 'salary', 'DIY', 'used' - whatever signals the wrong intent for this offer.
2. If a search terms report is provided, extract the actual irrelevant terms already wasting spend.
3. Group negatives into themes: wrong intent, wrong audience, free/cheap seekers, competitor names (decide whether to bid on or block), job seekers, informational-only terms.
4. Recommend match types for each negative (phrase or exact to avoid over-blocking; broad negatives can block too much).
5. Decide application level: account-level list for universal negatives, campaign or ad group for specific ones.
6. Output the themed negative lists with match types and application level.

## Output format

Themed negative keyword lists (wrong intent, wrong audience, free-seekers, etc.), each with recommended match types and where to apply them (account/campaign/ad group).

## Quality checklist

- [ ] Pre-launch negatives cover the obvious waste categories
- [ ] Real wasted terms from the search report are included where available
- [ ] Negatives are grouped by theme
- [ ] Match types avoid over-blocking (careful with broad negatives)
- [ ] Application level is specified for each list

## Optimization notes

Broad match negatives are double-edged: 'free' as a broad negative can block 'free shipping included'. Prefer phrase/exact negatives unless you truly want to block every variation. The biggest ongoing waste-killer is reviewing the search terms report weekly and adding negatives - pair with search-term-auditor.
