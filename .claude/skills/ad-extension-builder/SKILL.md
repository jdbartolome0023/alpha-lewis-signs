# ad-extension-builder

*Cluster: Ad Copy & Assets . Part of the 35 Google Ads Skills set by Vicky Lalwani, Digital Marketing Director.*

## Purpose

Build the full set of ad extensions (assets) that expand ad real estate, add value, and lift CTR - sitelinks, callouts, structured snippets, and the rest - matched to the campaign.

## When to use

- Setting up extensions for a new campaign
- Improving CTR by expanding ad real estate
- Filling in missing extension types
- Refreshing extension copy

## Inputs required

- The business, products, and key pages (required)
- The campaign theme (required)
- Optional: the offer, USPs, locations, the landing pages for sitelinks

## Step-by-step instructions

1. Identify which extension types fit: sitelinks (key pages), callouts (USPs/benefits), structured snippets (categories/types), call, location, price, promotion, lead form, image.
2. Write sitelinks pointing to the most useful pages, each with a benefit-led description.
3. Write callouts as short, punchy benefit phrases (free shipping, 24/7 support, no contract).
4. Write structured snippets using a valid header and relevant values.
5. Recommend price, promotion, image, and call/location extensions where the business supports them.
6. Output all extension copy by type, within character limits, with notes on which drive the most CTR lift.

## Output format

A complete extension set by type (sitelinks, callouts, structured snippets, etc.), within limits, with the landing page or value for each and a note on CTR impact.

## Quality checklist

- [ ] All relevant extension types are covered
- [ ] Sitelinks point to genuinely useful pages with benefit descriptions
- [ ] Callouts are short, distinct benefit phrases
- [ ] Structured snippets use a valid header and real values
- [ ] Everything is within character limits

## Optimization notes

Extensions are free CTR and free real estate - more extensions mean a bigger, more prominent ad, and Google rewards full asset coverage. Most accounts under-use them. The fastest CTR win on a mature account is often just filling in the missing extension types, no bidding or copy changes needed.
